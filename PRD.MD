Ini adalah draf Project Brief / PRD (Product Requirements Document) untuk proyek redesain web Decant TELBA berdasarkan arahan gaya visual terbaru yang Anda berikan.
Project Brief: Decant TELBA Management System Redesign
1. Project Overview

Redesain platform manajemen internal Decant TELBA (sistem input penjualan decant) untuk menyelaraskan identitas visual dengan brand utama TELBA (telba.xyz). Fokus utama adalah mengubah tampilan dari gaya "utility" yang sederhana menjadi portal manajemen yang premium, eksklusif, dan profesional.
2. Brand Identity & Style Guide (Ref: telba.xyz)

    Aesthetic: Luxurious, Dark, Warm, Minimalist.
    Color Palette:
        Primary: Deep Chocolate Brown (#2A1B15) / Charcoal Black.
        Accent: Cream, Gold, atau Champagne untuk teks penting dan tombol.
        Neutral: Grey gelap untuk border dan elemen sekunder.
    Typography: Kombinasi Serif yang elegan untuk Heading (memberikan kesan timeless) dan Sans-Serif yang bersih untuk data/teks input.

3. Key Features & Functionality
A. Sales Input Module (Redesigned)

    Smart Selection: Dropdown pencarian untuk brand dan varian parfum untuk mempercepat input.
    Volume Selection: Toggle button modern (5ml, 10ml, etc.) daripada sekadar input teks manual.
    Payment & Source Tracking: Input metode pembayaran (QRIS/Cash) dan sumber pesanan (WA, Tokopedia, Shopee).

B. Dashboard Analytics

    Sales Summary: Ringkasan total penjualan harian/bulanan.
    Stock Status: Indikator visual untuk stok botol decant atau parfum induk yang mulai menipis.
    Quick Actions: Tombol akses cepat untuk menambahkan data baru atau mengekspor laporan.

C. Data Management

    Recent Transactions: Tabel transaksi terbaru dengan sistem filter yang rapi.
    Database Integration: Sinkronisasi database produk yang dimuat secara otomatis (seperti pada versi asli).

4. User Experience (UX) Goals

    Desktop-First: Karena ini adalah sistem manajemen, fokus pada efisiensi penggunaan di layar besar/laptop.
    Reduced Friction: Meminimalkan jumlah klik untuk menyelesaikan satu entri penjualan.
    Luxury Feel: Meskipun ini alat internal, desain harus mencerminkan nilai brand TELBA yang menjual pengalaman dan aroma.
